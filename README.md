# 🎮 Tic Tac Toe Game

A fully interactive and responsive **Tic Tac Toe web game** built using **HTML, CSS, and JavaScript**.  
This project features a modern UI, score tracking, winner detection, restart functionality, and a basic AI opponent.

---

## 🚀 Live Demo
https://serene-cascaron-257e14.netlify.app/

---

## 📌 Features

- ✅ Modern responsive user interface
- ✅ Player vs Computer gameplay
- ✅ Winner detection algorithm
- ✅ Draw game detection
- ✅ Live scoreboard
- ✅ Restart game button
- ✅ Winning cells highlight
- ✅ Smooth click animations
- ✅ Mobile responsive layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation + Game Logic)

---

## 🧠 Game Logic Used

The project uses:

- JavaScript Arrays for board state management
- Event Listeners for cell click actions
- Conditional winner checking algorithm
- Random AI move generation for computer player
- Dynamic DOM updates for smooth gameplay
